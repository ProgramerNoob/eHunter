# 下载、阅读偏好与放大镜决策

- **确认日期**：2026-09-18。
- **适用范围**：下载格式、翻页默认值与存储、放大镜尺寸与可视边界。
- **使用规则**：修改下载元数据、翻页默认值、偏好存储/迁移或放大镜时，先读取本文。本文对应条款替代旧规格中的冲突描述；其余需求继续有效。

## 1. 下载格式

每个 ZIP 分包包含一个 UTF-8 `metadata.json`，保留七个字段：`introUrl`、`galleryTitle`、`totalPages`、`downloadTime`、`eHunterVersion`、`totalChunks`、`chunkIndex`。单包和多包都独立携带元数据。

沿用现有 `fflate` 生成标准 ZIP；元数据采用 JSON 单格式，不使用 YAML。当前生产者见 [GalleryDownloadService.ts](../../../../core/service/GalleryDownloadService.ts)；仓库内没有读取该元数据的消费者。

**完成标准**：下载规格及验收统一检查 `metadata.json`，每包七个字段完整且分片信息正确。`downloadTime` 要求用户本地时区，当前生产者为 UTC `toISOString()`；抓取要求顺序执行，当前实现为三个并发 worker——两处差异见[功能索引](../features/index.md#已知状态差异)。

## 2. 翻页默认值

翻页动效的默认档位由首次初始化时的系统/设备条件决定，结果随后持久化；后续系统变化或保存其他设置不触发重算。合法旧值优先于重算，缺省或非法值才走初始化。

**完成标准**：首次系统/设备矩阵符合上述规则并被记录；共享、逐项迁移、降级与重置防复活各有证据；三档动效在两种阅读模式回归通过。

## 3. 设置共享与迁移

共享存储以用户脚本存储为唯一权威通道；本页 `localStorage` 只是同一 origin 的降级镜像，仅在不具备用户脚本存储时参与共享读写。非法值一律等同缺失，不做静默钳制，由迁移与默认值补齐。逐项迁移按「共享数据 → 本站统一旧值 → 站点独立旧值 → 默认值」补缺，重复执行结果一致。显式重置后写入统一身份，重置前旧副本按缺失处理但不删除；共享通道仍健康时读到重置标记即锁定为已重置，避免被清掉的旧设置复活。

**完成标准**：真实 EH/EX/NH 环境下验证合法值优先、逐项补缺、重复迁移幂等与重置防复活。

## 4. 放大镜尺寸、记忆与可视边界

### 尺寸与入口

桌面设置与快捷菜单使用同一组尺寸与倍率范围，接收任意整数，跨界时按边界钳制并在边界处禁用对应操作。镜头边长 = 取样尺寸 × 倍率。

### 记忆范围

尺寸与倍率长期共享，跨会话保存，随共享/降级/迁移/重置规则处理；放大镜开关只在页面会话内继承，不写入持久偏好。

### 放不下时的显示规则

镜头完整处于 `PageView ∩ viewport` 交集内：有空间时避开焦点，空间不足时允许覆盖焦点；受限时窗口与取样框同步缩小以保持倍率关系（含小于 20px 的边界），空间恢复后还原。滚动、窗口与布局变化触发重算且不改偏好。

**完成标准**：验证自由整数值、20/300 边界、快捷加减与设置一致性、尺寸/倍率跨会话保存、开关会话继承，以及窗口缩小时保持倍率和完整可见、窗口恢复时还原范围。桌面端验证两个阅读模式；移动端验证原有阅读和菜单行为、放大镜桌面端限制。
