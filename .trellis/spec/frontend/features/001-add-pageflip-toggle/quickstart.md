# Quickstart: 书页模式翻页动效开关

**状态**：已同步 [2026-09-18 决策](../../decisions/2026-09-18-reader-behavior.md) 第 2、3 节。以下为待执行步骤及预期，本次文档同步不代表功能验收通过。

## 1. 准备环境

按 [项目验收要求](../../../../../AGENTS.md) 通知、准备依赖，并按 [浏览器指南](../../browser-acceptance.md) 后台启动 `npm run dev`；检查 Vite 错误和控制台。桌面使用 1200×900，移动使用 390×844。共享与降级用例使用隔离的测试偏好，在真实油猴脚本环境通过 [eh-test](../../../../../.pi/skills/eh-test/SKILL.md) 验证 EH/EX，并补验 NH，避免改动日常偏好。

## 2. 首次初始化矩阵

每组开始前准备无合法共享及本站旧偏好的测试状态，先设设备/系统条件再初始化；确认 UI、实际翻页和持久化结果一致。

| 环境 | 系统减少动态效果 | 预期动效 |
| --- | --- | --- |
| 桌面 | 关闭 | 拟真 |
| 移动 | 关闭 | 平移 |
| 桌面 | 开启 | 无动效 |
| 移动 | 开启 | 无动效 |

1. 初始化后切换系统偏好，确认当前动效不变。
2. 保存语言等其他设置，再刷新和重开画集，确认仍使用已保存结果。
3. 分别预置三种合法偏好，在上述四种环境初始化，均保留原值；旧记录恰等于旧默认拟真也保留。
4. 预置缺失/坏值，确认先由本站合法旧值补齐，所有来源都无合法值才使用矩阵；执行明确重置后重新初始化，确认不会重导被重置的旧值。

## 3. 三档动效及阅读回归

1. 进入书页模式，在设置区依次选择拟真、平移、无动效，每次执行上一页/下一页；下一次翻页使用所选动效。
2. 使用点击、滚轮、键盘、自动翻页，确认均使用同一有效设置。
3. 第一页向前、末页向后不能越界；加载未完成和快速连续输入不能产生页码错乱、明显积压或长时间空白。
4. 切换卷轴模式，原滚动行为保持；返回书页仍使用已确定的偏好。
5. 两种视口均检查布局和关键交互，桌面确认动画流畅、反馈及时；记录规格中可发现性和持续生效指标的实际覆盖情况。

## 4. 共享、迁移与重置

执行 [设置 quickstart](../002-more-settings-modal/quickstart.md) 的“共享与迁移矩阵”。动效作为被测字段，同时覆盖其他字段：合法共享优先、统一旧值优先于独立旧值、空共享首次迁入、后续站点只补缺、坏值修复、重复迁移、GM 不可用的 origin 隔离、GM 恢复及重置防复活。GM 可用时在 EH/EX/NH 间重开阅读器检查一致性；无需假设已打开页面实时同步。

## 5. 完成标准与证据

实施后运行 `npm run type-check`；涉及生产注入按 eh-test 执行构建与实际脚本验证。记录测试日期、提交/工作区版本、浏览器/脚本环境、矩阵结果和截图位置。上面每项均有通过证据或明确未覆盖原因后再更新 tasks；历史勾选不替代新规则验收。
