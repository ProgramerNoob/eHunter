## 4) Runtime Verification

### US1 / US3：菜单与原有阅读行为

桌面 1200×900：

1. 卷轴模式单击图片打开菜单；书页模式点击现有中间留白区且命中 PageView 才打开菜单，非中央区域仍正常翻页。
2. 检查“加载原图”始终显示：支持换源时点击只触发当前 PageView 原图加载；不支持时禁用并显示原因。
3. “奇偶切换”仅书页模式显示且可执行；菜单关闭、模式切换后无旧菜单残留。
4. 桌面关闭放大镜时隐藏倍率/尺寸快捷项，开启后显示；仅当前交互页出现镜头，其他 PageView 无镜头残留。

移动 390×844（iPhone 12 Pro，触摸输入）：

1. 卷轴模式长按满 500ms 打开菜单；不足 500ms、位移超过 10px、滑动、抬起、取消或多指触摸不误触发。
2. 放大镜开关、尺寸与倍率入口均不可见；保留原有菜单、滚动和阅读交互。
3. 检查不支持平台的“加载原图”禁用说明，以及书页中央菜单与非中央翻页互不冲突。
4. 保存两个视口的菜单、禁用态和阅读交互截图；按 spec 的 SC-001/005/006 记录参与者、事件样本和基线比较，不能仅凭单次操作宣称达标。

### US2-A：尺寸、倍率与边界

以下在桌面书页/卷轴两模式分别执行：

1. 使用无合法偏好的夹具初始化：开关关闭，设置显示 80px、3x。空间充足时开启放大镜，测量参考框 80px、镜头 240px，并检查白色约 30% 不透明度、主题绿色边框和阴影。
2. 设置依次输入 21、27、83、295、299px，确认每个整数原样生效；设置 83px 后快捷增大为 93、减小回 83，重新打开设置也显示相同值。
3. 设置 27px 后快捷减小得到 20，减小按钮禁用；再增大为 30。设置 295px 后增大得到 300，增大按钮禁用；再减小为 290。分别从设置和快捷菜单到达 20/300，确认边界状态一致。
4. 设置尝试 19、301、80.5 及非数字，确认不会形成范围外或非整数的已提交偏好；再输入合法值应可继续操作。
5. 通过设置选择及快捷增减遍历 2x/3x/4x/5x；每次只增减一档，2x 的减小和 5x 的增大按钮禁用，两个入口反映同一值。
6. 关闭/重开菜单确认文案；鼠标离开 PageView 后参考框和镜头隐藏，开关仍为开启。图片待加载/失败时菜单可用，显示可理解的占位状态，图片可用后才显示正确放大内容。

### US2-B：可视交集、受限缩小与空间恢复

以 CSS px 测量 PageView、viewport、参考框和镜头的矩形；保存测量值及截图。每项在两个阅读模式执行，窗口调整保持桌面细指针环境。

1. 空间充足时，将焦点依次移到中央、四边、四角。镜头优先在焦点旁避让；默认右侧越界时换到其他可用位置，镜头四边均在 `PageView ∩ viewport` 内。
2. 卷轴中滚动到 PageView 部分出视口；书页中调整窗口或面板使 PageView 可视范围缩小。再次测量交集，确认边界依据交集而非整个 PageView 或单独 viewport。
3. 设定 200px、5x，将交集最大可容纳正方形边长调至 600px：参考框应为 120px，镜头为 600px。若实际边长为 L，则预期参考框为 `min(200, L/5)`，镜头为其 5 倍；不能只裁镜头或降倍率。设置和存储仍显示 200px、5x。
4. 保持 5x，通过窗口/布局或 PageView 部分移出视口，使交集最大正方形边长小于 100px 且焦点仍有效：实际参考框必须可小于 20px，镜头仍完整可视。若避开焦点放不下，允许覆盖部分焦点；记录重叠和边界，不按旧的绝对不遮挡规则判失败。
5. 在同一页面恢复空间：当交集可容纳 1000px 正方形时，自动恢复 200px 参考框和 1000px 镜头；若测试设备上限不足，另设 80px、3x，先缩到 L<240，再恢复 L≥240 验证 80/240。记录哪组实际执行。
6. 缩小与恢复期间不重新设置尺寸、不切换开关，检查滚动、resize、PageView 布局变化均可重算；临时尺寸不写回偏好。完全离开可视区域时隐藏显示层，返回后按原偏好显示。

### US2-C：长期偏好与页面会话

1. 设置 137px、4x 并开启放大镜；翻页再返回、书页↔卷轴切换，确认开关仍开启、设置仍为 137/4，仅当前交互页显示。
2. 刷新页面，再打开同站新页面：两者均应恢复 137px、4x，但开关关闭。即使另一页面仍开启放大镜，新页面也默认关闭。
3. 同一浏览器、同一脚本安装下，在 EH 保存 137/4，打开 EX、NH 确认恢复同值；在 NH 改为 83/2，再在 EH/EX 新页面确认。每次均检查开关关闭。不以本地开发页替代 GM 共享验收。
4. GM 不可用夹具：在一个 origin 保存 127/5并刷新，预期恢复本站值；另一个 origin 保持自己的值，确认 localStorage 降级隔离。
5. 对尺寸和倍率分别执行迁移矩阵（详细优先级以决策第 3 节为准），比较最终 UI 与存储：

| 夹具 | 操作与预期 |
| --- | --- |
| 共享合法、本站旧值冲突 | 初始化，合法共享值保留 |
| 共享缺失或无效、本站统一值合法 | 只补该项；同站统一值优先于旧独立值 |
| 本站统一项无效、旧独立项合法 | 用旧独立合法值补缺 |
| 共享为空、两个站点旧值不同 | 首站迁入，后站只补仍缺失/无效项，重复打开结果一致 |
| 某项在全部来源均无合法值 | 该项回默认 80px 或 3x；另一合法项保持。覆盖小数、越界及非数字坏值 |
| GM 恢复、共享合法值与降级期间本站值冲突 | 初始化后保留共享合法值 |
| 明确重置偏好、仍有旧副本 | 按现有确认流程重置，再打开；默认值生效，旧副本不能重新导入 |

6. 在受限空间中保存其他设置并刷新，确认恢复的仍为用户设定尺寸/倍率，临时取样、镜头尺寸和开关未持久化。
