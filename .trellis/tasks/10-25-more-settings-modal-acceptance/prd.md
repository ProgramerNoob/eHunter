# 验收 002-more-settings-modal

## Goal

执行 [002-more-settings-modal quickstart](../../spec/frontend/features/002-more-settings-modal/quickstart.md) 的全部验收步骤，覆盖弹窗交互与阅读回归、共享/迁移/重置矩阵、翻页与放大镜专项，产出可核验的验收记录。

## Background

该组的弹窗与阅读回归部分未执行，共享/补缺/降级/重置矩阵、翻页初始化与放大镜持久化的桌面与移动回归同样未执行，`pending-work.md` 将其列为未收口项。功能已实现并在 `core/` 下，本轮只验收不改代码。

环境要求分两层：

- 弹窗交互与阅读回归（quickstart 第 2 节）可在本地 Vite + `ego-browser` 的 `desktop`（1200×900）/ `mobile`（390×844）执行。
- 共享、坏值及重置用例（第 3 节）必须先完成共享/补缺/重置规则，再验证交互；要求隔离的测试脚本安装与测试偏好，保留日常偏好；分别在 GM 可用与不可用环境验证，且不能把 localhost 或 localStorage 结果当成 GM 跨站证据。走 [reader-test](../../../.pi/skills/reader-test/SKILL.md) 生产包链路。
- 放大镜专项依赖 [001-add-pageview-magnifier quickstart](../../spec/frontend/features/001-add-pageview-magnifier/quickstart.md)；翻页专项依赖 [001-add-pageflip-toggle quickstart](../../spec/frontend/features/001-add-pageflip-toggle/quickstart.md) 的首次初始化矩阵。

决策依据：[2026-09-18 决策](../../spec/frontend/decisions/2026-09-18-reader-behavior.md) 第 2–4 节。

## Requirements

- R1 执行第 2 节弹窗与阅读回归：顶栏打开/关闭更多设置、旧二层入口不再出现、关闭后阅读位置保留；五个分类跳转、平滑滚动与高亮；逐分类核对全部既有公开配置（含原高级项）修改立即生效且重开显示正确、中英日文案可见；阅读模式固定第一位且不可取消/拖拽，其他快捷项可勾选排序且两模式按同一全局顺序过滤；GitHub 链接与版本号正常；重置先提示、取消无变化、确认后有成功/失败反馈且缓存与设置按既有范围重置。
- R2 执行第 3 节共享与迁移矩阵全部九行场景，以翻页动效、语言、快捷项顺序、放大镜尺寸/倍率为代表字段，记录每例迁移前后各来源的值；同时核实生产脚本的 GM 读写/重置能力与权限声明，确认单个坏值修复不影响其余合法值。
- R3 执行第 4 节相关设置专项：翻页（首次初始化矩阵，无合法迁移值时按系统减少动态效果与设备给出默认，三种已有合法值保留，初始化后不因切换系统偏好或其他设置保存而意外变化）；放大镜（桌面设置与快捷菜单范围一致、任意整数 20–300、快捷 ±10 并钳制边界、尺寸与倍率长期保存、开关仅当前页面会话继承、视口受限的临时尺寸不写回偏好、移动端保留桌面限制）。
- R4 桌面与移动两个 profile 各跑本地轮；平台轮按 reader-test 记录 bundle/loader 证据。每轮用 `python3 scripts/acceptance.py verify-browser <artifact-dir>` 校验并按结果回填。
- R5 运行 `npm run type-check` 并在记录中附结果。
- R6 不改产品代码；发现缺陷只记录。

## Acceptance Criteria

- [AC1] 弹窗交互：顶栏可打开/关闭更多设置，旧二层入口不再出现，关闭后阅读位置保留；五个分类跳转、平滑滚动与高亮正确，窄屏布局可读可操作。
- [AC2] 逐分类核对全部既有公开配置（含原高级项）：修改立即生效，重开显示正确，中英日文案可见；阅读模式固定第一位且不可取消/拖拽，其他快捷项可勾选排序，两模式按同一全局顺序过滤。
- [AC3] GitHub 链接与版本号正常；重置先显示明确提示，取消无变化，确认后有成功/失败反馈，缓存与设置按既有范围重置。
- [AC4] 共享与迁移九行矩阵在 GM 可用与不可用的真实脚本环境下逐行有结论（合法共享优先、统一旧值先迁入且后续站点不覆盖、逐项补缺不被整体覆盖、重复迁移结果相同、origin 隔离、降级后恢复补缺、重置防复活）；生产脚本的 GM 读写/重置能力与权限声明已核实。
- [AC5] 翻页专项：无合法迁移值时按系统减少动态效果与设备取默认，三种已有合法值保留，初始化后切换系统偏好或保存其他设置不改变动效。
- [AC6] 放大镜专项：桌面设置与快捷菜单范围一致，任意整数 20–300，快捷 ±10 且边界钳制；尺寸与倍率长期保存，开关仅当页会话继承，视口受限的临时尺寸不写回偏好，移动端保留桌面限制。
- [AC7] 桌面与移动两轮本地验收、平台轮均产出通过 `verify-browser` 校验的预检产物，`npm run type-check` 结果与 `summarize` 输出实际记录。
