# 执行计划

## 依赖
可先只读研究现有项目控制点；真实子代理对照须等子任务一验证主动压缩能力。
同一 .pi/ 文件仅一个写入者；开始前确认上一轮编码与审查均已结束。

## 步骤
- [x] 读取本轮版本与配置来源，仅针对相关键核查默认值、环境变量和项目级覆盖能力，结果存入 research/。
- [x] 检索本项目中要求精确状态、读取清单与压缩后恢复的权威规则，列出必要读取与冗余读取的区别。
- [x] 建立有限收口样例；日志放 .tmp/trellis-acp-reread-loop/，预设最多 20 个模型轮次、单次最长 5 分钟，运行过程保持可观察。
- [x] 发短通知后运行基线；一旦达到 PRD 的空转判据就保存证据并结束该次实验，避免重演长时间空转。
- [x] 按设计验证局部控制或状态读取最小修复；不一次改动多个未经验证的因素。

- [x] 相同条件复跑，验证关键事实、实际交付与窗口保护，按主会话/子代理分别记录覆盖。

- [x] 固定最终版本，以 trellis-check 审查规范与验收证据，完成接受标准和回滚记录。

## 校验命令
```bash
python3 .trellis/scripts/task.py validate .trellis/tasks/10-13-trellis-acp-reread-loop
python3 scripts/acceptance.py summarize .trellis/tasks/10-13-trellis-acp-reread-loop
```
行为实验的最终命令随样例和生效控制点确定后写入 research/，不能将尚未支持的环境变量或 API 当作已可用命令。

## 停止与回滚
连续三次同类失败、窗口逼近上限、输出预算异常或到达实验上限时停止当前实验，整理证据。
如需要用户级配置才能解决，保持当前范围并返回规划说明；不自动改变配置。
回滚本子任务精确差异，保留原始证据和任务状态。

## 退出预算补充
退出探针定位当前 pi-graft 的 120 秒引用计时器。最终复测保留 300 秒模型执行与 20 请求限制，另记 130 秒清理预算（总上限 430 秒）；实际 191.426 秒正常退出，仍低于原总上限。旧 after2 超时保留，不修改原始结果。

最终审查记录：父任务 `research/final-review.md`，无阻塞项；验收以各任务 acceptance.json 的最终 summarize 为准。
