# 放大镜验收

## 背景

`.trellis/spec/frontend/features/001-add-pageview-magnifier/quickstart.md` 的验收步骤尚未执行，`pending-work.md` 记为未收口项。放大镜相关实现已存在（`core/components/composables/useMagnifier.ts`、`core/components/PageView.vue`），但尺寸/倍率边界、可视交集几何、跨会话持久化与真实油猴环境共享均缺少证据。

## 目标

按 quickstart 与 [2026-09-18 决策](../../spec/frontend/decisions/2026-09-18-reader-behavior.md) 第 3、4 节执行放大镜完整验收矩阵，逐项产出可审查证据（截图、几何测量、存储值、日志），并把结果回填到本任务 `acceptance.json`。

## 范围

- 本地 Vite：桌面 1200×900 与移动 390×844 两个固定 profile，书页与卷轴两种阅读模式，覆盖 US1/US3 菜单入口与上下文显隐、US2-A 尺寸倍率边界、US2-B 几何交集与受限恢复、US2-C 浏览器会话与本地持久化。
- 真实油猴：`dist/ehunter.iife.js` 在 EH 与 NH 通过准备门，验证 EH/EX/NH 共享合法尺寸与倍率、开关不跨会话；GM 不可用降级、迁移/坏值/重置矩阵按 fixture 与真实环境可观察部分分别取证。
- 静态：`npm run type-check`。

## 非目标

- 不改产品代码。验收发现的缺陷只记录失败项、复现步骤与证据，另建修复任务。
- 不重跑其它六组功能的 quickstart；不清理用户缓存、设置或已登录会话。
- 不新增固定 profile 或修改 `scripts/browser-preflight.mjs`；690×1044 等其它视口不属于本轮。

## 约束

- 每轮使用新的绝对 `artifactDir` 与仓库内 `scenarioInputs` 快照；helper 是唯一 `page.events()` 消费者；产物保存到 `.tmp/`。
- 几何断言用 CSS px 的 `getBoundingClientRect()` 实测值，保存测量记录与截图，不以目测替代；受限空间必须实际构造并记录 `L`（交集最大可容纳正方形边长）。
- 长按 500ms、防误触等时序结论在 note 中记录 coverage 对时序的影响，不把单次操作写成 SC-001/005/006 达标。
- 迁移矩阵逐行记录初始共享值、本站统一值、站点独立值与最终 UI/存储值；坏值覆盖小数、越界与非数字。
- 每轮结束运行 `python3 scripts/acceptance.py verify-browser <artifact-dir>`；准备 blocked 与产品 failed 分开记录。
- EX 不可访问（未登录/403）时记 blocked 并说明未执行范围；NH 429 先冷却，不归为产品失败。

## 接受标准

- [AC1] `npm run type-check` 退出码 0；本地 Vite 服务归属核实后可访问，页面无 `vite-error-overlay`，阅读器可正常打开。
- [AC2] 桌面卷轴单击图片、书页点击中间留白区且命中 PageView 打开菜单，非中央区域仍翻页；移动卷轴长按满 500ms 打开，短按、位移超过 10px、滑动、抬起、取消与多指触摸不误触发；桌面关闭放大镜时隐藏倍率/尺寸项、开启后显示；"加载原图"始终显示并按平台能力启用或禁用且给出原因；"奇偶切换"仅书页模式显示；移动端不显示放大镜开关、倍率与尺寸项；菜单关闭与模式切换无残留，仅当前交互 PageView 出现镜头。
- [AC3] 无合法偏好时默认 80px/3x；尺寸 20–300 任意整数原样生效，快捷增减每次 10px 且跨界钳制到 20/300、边界按钮禁用；设置与快捷菜单显示同一值；19、301、80.5 与非数字不形成已提交偏好；倍率仅 2x/3x/4x/5x，每次一档，2x 减小与 5x 增大禁用；鼠标离开 PageView 后参考框与镜头隐藏而开关保持；图片待加载或失败时菜单可用并显示可理解占位。以上在书页与卷轴两模式分别验证。
- [AC4] 镜头四边均在 PageView∩viewport 内，焦点在中央/四边/四角时优先避让；设定 200px/5x 且交集最多容纳 600px 时实际参考框 120px、镜头 600px；交集最大正方形边长小于 100px 时参考框可小于 20px 且镜头完整（放不下允许覆盖焦点）；空间恢复到 L≥1000 时还原 200px 参考框与 1000px 镜头（设备不足时改用 80px/3x 与 L≥240 组并记录）；受限与恢复期间设置、倍率与开关不变，临时尺寸不写回偏好；滚动、resize 与布局变化重算；完全离开可视区域隐藏，返回后按原偏好显示。以上在两模式分别验证。
- [AC5] 设置 137px/4x 并开启后，翻页往返与书页↔卷轴切换保留开关与 137/4，仅当前交互 PageView 显示；刷新页面与打开同站新页面恢复 137/4 但开关关闭；受限空间中修改其他设置并刷新后仍恢复用户尺寸与倍率；临时取样、镜头尺寸与开关未持久化。
- [AC6] EH 与 NH 生产包均通过准备门；EH 保存 137/4 后 EX 与 NH 新页面恢复同值且开关关闭；NH 改为 83/2 后 EH/EX 新页面恢复 83/2；共享以实际脚本存储为唯一权威通道，每轮 `verify-browser` 返回 passed。
- [AC7] GM 不可用时一个 origin 保存 127/5 刷新恢复本站值、另一 origin 保持自身值；迁移矩阵逐行验证「共享合法 } 共享合法优先，本站旧值冲突不覆盖；共享缺失或无效补本站统一值；统一项无效回旧独立值；共享为空且两站旧值不同时首站迁入、后站只补缺失、重复打开一致；全部来源无合法值回 80/3 且覆盖小数/越界/非数字；GM 恢复且共享合法时保留共享值；显式重置后旧副本不复活」；记录实际初始值与最终 UI/存储值。
