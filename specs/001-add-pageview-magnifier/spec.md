## Clarifications

### Session 2026-02-24

- Q: 放大镜是否在移动端可用？ → A: 仅桌面端可用；移动端菜单不显示放大镜相关项。
- Q: 切换到新 PageView 后放大镜状态如何处理？ → A: 会话内跨页继承放大镜开关状态与当前倍率。（历史澄清；记忆范围已由 2026-09-18 决策扩展为尺寸、倍率长期保存，开关仅当前页面会话。）
- Q: 移动端长按触发阈值是多少？ → A: 固定 500ms。
- Q: 平台不支持换源刷新时，“加载原图”如何呈现？ → A: 菜单项保留但置灰禁用并显示不支持原因。
- Q: 书页模式用于打开菜单的中央区域如何定义？ → A: 与现有书页模式“中间留白区”定义完全一致。

## User Scenarios & Testing *(mandatory)*

**Validation Note**: For each completed development cycle, run `npm run dev` and verify changed behavior in browser using `ego-browser` before marking work complete.

### User Story 1 - 快速打开页面菜单 (Priority: P1)

作为阅读中的用户，我希望在不同阅读模式下都能用符合设备习惯的手势快速打开页面菜单，这样我无需离开当前页面即可执行关键操作。

**Why this priority**: 菜单入口是所有后续能力（放大镜、加载原图、奇偶切换）的前提，若无法稳定打开，功能整体不可用。

**Independent Test**: 在滚动模式与书页模式中分别触发对应手势，验证菜单是否在预期条件下弹出，并且不会误触发与模式冲突的翻页行为。

**Acceptance Scenarios**:

1. **Given** 用户处于滚动模式且使用桌面端设备，**When** 单击当前图片区域，**Then** 页面菜单在当前 PageView 上弹出。
2. **Given** 用户处于滚动模式且使用移动端设备，**When** 对当前图片持续按压达到 500ms，**Then** 页面菜单在当前 PageView 上弹出。
3. **Given** 用户处于书页模式，**When** 点击与现有书页模式“中间留白区”定义一致且覆盖到 PageView 的位置，**Then** 打开页面菜单且不触发上下翻页。

### User Story 2 - 使用放大镜查看细节 (Priority: P2)

作为桌面端阅读中的用户，我希望在当前 PageView 内开启放大镜并调整取样尺寸和倍率，以便快速查看局部细节而不改变整体阅读进度。

**Why this priority**: 放大镜是本需求的核心价值，直接提升细节查看体验，且不应影响主阅读流程。

**Independent Test**: 在桌面端两个阅读模式中检查开关、尺寸和倍率调节、焦点框与镜头的几何关系、可视边界及空间恢复，再检查长期偏好与页面会话开关；移动端验证不展示放大镜相关项。

**Acceptance Scenarios**:

1. **Given** 当前页面会话初次开启阅读器且没有合法已存偏好，**When** 用户从菜单选择“打开放大镜”，**Then** 当前 PageView 按默认取样 80×80 CSS px、3x 显示，菜单文案变为“关闭放大镜”。
2. **Given** 放大镜已开启且空间充足，**When** 用户移动鼠标，**Then** 焦点处显示与设定取样边长一致的半透明白色参考框，正方形镜头边长等于参考框边长乘以所选倍率，并优先置于焦点右侧。
3. **Given** 默认位置超出 PageView 与视口的交集，**When** 焦点移动到边缘，**Then** 镜头优先换到不遮挡焦点的可用位置；空间不足时允许覆盖部分焦点，确保镜头完整可视。
4. **Given** 当前倍率为 3x，**When** 用户通过设置或快捷菜单调节倍率，**Then** 仅在 2x/3x/4x/5x 中选择，实时生效并长期保存；快捷增减每次一档，边界对应按钮禁用。
5. **Given** 用户已开启放大镜，**When** 同一页面内翻页或切换书页/卷轴模式，**Then** 继承开关、尺寸与倍率；刷新或打开新页面后，尺寸与倍率恢复已存值，开关为关闭。
6. **Given** 设置尺寸为任意合法整数（如 27 或 295px），**When** 使用快捷加减，**Then** 每次增减 10px，27→20、295→300 在跨界时钳制，20/300 的减小/增大按钮禁用；设置与快捷菜单立即反映同一值。
7. **Given** 设定取样 200px、倍率 5x，而可视交集最多容纳 600px 正方形，**When** 显示放大镜，**Then** 实际参考框为 120px、镜头为 600px，倍率仍为 5x，设置仍为 200px/5x；空间足够后自动恢复 200px 参考框和 1000px 镜头。
8. **Given** 同一浏览器、同一脚本安装已保存尺寸与倍率，**When** 在 EH/EX/NH 打开阅读器，**Then** 按决策第 3 节共享合法偏好；GM 不可用时按 origin 使用本站 localStorage 降级。

### User Story 3 - 按上下文显示菜单操作 (Priority: P3)

作为阅读中的用户，我希望菜单只展示当前场景可执行的操作，避免无效按钮和错误预期。

**Why this priority**: 上下文化菜单可降低误操作，提升功能可理解性与操作效率。

**Independent Test**: 在不同模式与平台能力下打开菜单，验证“加载原图”“奇偶切换”“倍率调整”等操作是否按条件显隐且可执行。

**Acceptance Scenarios**:

1. **Given** 当前平台支持换源刷新，**When** 打开页面菜单，**Then** 菜单显示“加载原图”操作并可触发原图加载。
2. **Given** 当前平台不支持换源刷新，**When** 打开页面菜单，**Then** 菜单保留“加载原图”操作但处于禁用状态，并显示不可用原因说明。
3. **Given** 当前为书页模式，**When** 打开页面菜单，**Then** 菜单显示“奇偶切换”操作；在滚动模式下不显示该操作。
4. **Given** 桌面端且放大镜关闭，**When** 打开菜单，**Then** 不显示倍率与尺寸调整操作；开启后显示这两类快捷操作。
5. **Given** 移动端设备，**When** 打开页面菜单，**Then** 不显示放大镜开关、倍率与尺寸调整操作。

### Edge Cases

- 用户在滚动模式移动端执行短按、滑动或点击时，不应误触发长按菜单（按压不足 500ms 不触发）。
- 移动端不应出现放大镜开关、倍率或尺寸操作入口，避免提供不可执行功能。
- 平台不支持换源刷新时，“加载原图”应保持禁用且不可触发实际加载。
- 用户在书页模式点击非中央留白区域时，应保持原有翻页交互，不弹出菜单。
- 放大镜开启后鼠标离开当前 PageView 时，放大镜与焦点框应立即隐藏，开关状态仍保留。
- 倍率处于 2x/5x、尺寸处于 20/300px 时，对应减小/增大按钮禁用；尺寸快捷跨界钳制，不能把自由整数吸附到旧预设档位。
- 跨页继承开启状态时，若新页面图片尚未可用，应延迟显示放大镜内容直到图片可被放大。
- 图片尚未加载完成或加载失败时，菜单仍可打开，但放大镜区域应显示可理解的占位状态而非错误内容。
- PageView 部分位于视口外、窗口缩小或布局变化时，以当前可视交集重算；可视交集为空时隐藏显示层，不修改设置或开关。
- 可视空间很小时，临时取样边长可小于 20px；镜头与参考框同步缩小且倍率不变，空间恢复即还原设定尺寸。优先避开焦点，放不下时允许覆盖焦点以保证镜头完整可视。
- 已存尺寸或倍率缺失、损坏时先按决策第 3 节补齐合法偏好，再使用默认值；临时几何结果不能写回偏好。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统必须在滚动模式下提供页面菜单入口：桌面端通过单击图片触发，移动端通过长按图片触发，且长按阈值固定为 500ms。
- **FR-002**: 系统必须在书页模式下仅允许通过与现有书页模式“中间留白区”定义一致的区域内、且命中 PageView 的点击来打开页面菜单，并保留该模式下非中央区域的现有翻页行为。
- **FR-003**: 页面菜单必须仅在桌面端包含“打开放大镜/关闭放大镜”单一切换项，文案需与当前放大镜状态一致；移动端不得显示该项。
- **FR-004**: 放大镜显示必须仅作用于当前交互的 PageView 实例；跨页共享偏好或继承开关不得使其他非交互页面同时显示镜头。
- **FR-005**: 放大镜默认倍率必须为 3x，允许倍率必须且仅为 2x、3x、4x、5x；默认取样边长为 80 CSS px，设置允许 20–300px 的任意整数。设置与快捷菜单必须使用同一尺寸、倍率及合法范围，能力仅适用于桌面端。
- **FR-006**: 桌面端放大镜开启时，菜单必须显示倍率与取样尺寸的增减操作，关闭时隐藏；移动端隐藏全部放大镜操作。倍率每次变更一档，尺寸每次增减 10px，跨界时钳制到 20/300；两类操作到达上下限后，对应按钮必须禁用。
- **FR-007**: 放大镜必须以正方形框显示，采用主题绿色边框与阴影样式，优先位于鼠标右侧等焦点旁可用位置。优先避开焦点；空间不足时允许覆盖部分焦点，以保证镜头完整可视。
- **FR-008**: 可用区域必须为当前 PageView 与浏览器视口的交集。默认位置越界时换侧或选择可用位置；设定尺寸生成的镜头无法完整放下时，保持所选倍率并临时缩小取样参考框和镜头，使镜头完整处于交集内。临时取样可小于 20px，不改已存尺寸/倍率；窗口或布局恢复空间后立即恢复设定取样范围。
- **FR-009**: 桌面端放大镜开启且鼠标位于当前 PageView 内时，系统必须在焦点处显示约 30% 不透明度的白色正方形参考框，标识实际取样范围。空间充足时边长等于设定值（默认 80px），受限时使用 FR-008 的临时边长；始终满足“镜头边长＝实际取样边长×所选倍率”。移动端不显示参考框。
- **FR-010**: 页面菜单必须始终展示“加载原图”操作；当平台支持换源刷新时该操作可用，当平台不支持时该操作必须置灰禁用并提供不可用原因说明。
- **FR-011**: 用户触发“加载原图”后，当前 PageView 必须改为使用原图源进行加载。
- **FR-012**: 页面菜单必须仅在书页模式下显示“奇偶切换”操作，在滚动模式下不得显示。
- **FR-013**: 放大镜、焦点框和菜单的显示/隐藏必须跟随当前 PageView 的交互上下文变化（如离开视图、模式切换、关闭菜单），避免残留；显示层清理与 FR-014 的开关会话继承分开处理。
- **FR-014**: 尺寸与倍率必须长期保存，遵循决策第 3 节的 GM 共享、GM 不可用时按 origin 的 localStorage 降级、逐项迁移及重置规则；同一浏览器、同一脚本安装下 EH/EX/NH 共用合法偏好。开关仅在当前页面阅读会话中继承，翻页和书页/卷轴切换保留，刷新或打开新页面默认关闭。首次使用且无合法已存偏好时为关闭、80px、3x。

### Key Entities *(include if feature involves data)*

- **PageView Interaction Context**: 当前交互页面、阅读模式、设备类型、中央菜单区域命中情况与 PageView/视口可视交集。
- **Page Menu Action Set**: 操作名称、可见条件、可执行条件，含尺寸与倍率边界禁用状态。
- **Magnifier State**: 当前页的开关、所选倍率/取样边长、实际临时取样边长、镜头边长及显示位置。
- **Magnifier Session Preference**: 当前页面会话继承的开关状态；刷新或新页面重新关闭。
- **Magnifier Persistent Preference**: 长期保存的尺寸与倍率，跨站共享/降级遵循权威决策。
- **Focus Indicator**: 实际取样参考框的尺寸、显示状态、位置与约 30% 不透明度。

## Assumptions

- “透明白色（大约305透明度）”按产品意图解释为“约 30% 不透明度的白色覆盖层”。
- 放大镜倍率切换以相邻档位递增/递减方式进行，每次操作变更 1 档。
- “加载原图”仅针对当前 PageView 正在展示的图片生效，不批量作用于其他页面。
- 只有开关属于页面会话状态；尺寸、倍率属于长期偏好。可视空间变化只影响临时几何，不改变偏好。

## Dependencies

- 菜单需依赖已存在的“平台是否支持换源刷新”能力判断结果。
- 书页模式菜单触发区域直接复用现有“中间留白区”定义，以与全局翻页手势进行冲突规避。
- PageView 需能够识别当前输入环境（桌面端/移动端）与基础指针事件。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 在可用性验收中，90% 以上测试参与者可在 3 秒内通过正确手势打开页面菜单（分别覆盖滚动桌面端、滚动移动端、书页模式）。
- **SC-002**: 在边缘、视口缩小与恢复的交互样本中，镜头完整处于 PageView∩viewport 的比例为 100%；有空间时避开焦点，空间不足允许覆盖焦点。参考框与镜头同步缩放，所选倍率和已存尺寸不变，恢复空间后还原设定范围。
- **SC-003**: 100% 的倍率及尺寸用例符合四档倍率、任意整数 20–300px、快捷 ±10px 跨界钳制和边界禁用要求；尺寸/倍率的长期保存与开关的页面会话行为均符合 FR-014。
- **SC-004**: 在菜单上下文展示测试中，针对“加载原图”“奇偶切换”“倍率与尺寸调整”的显隐条件准确率达到 100%。
- **SC-005**: 在完整阅读回归中，书页模式非中央区域翻页成功率与改动前基线保持一致（允许误差不超过 2%）。
- **SC-006**: 在移动端手势验收中，按压不足 500ms 的触控事件误触发菜单比例低于 1%。
