## 3. 共享与迁移矩阵

以翻页动效、语言、快捷项顺序、放大镜尺寸/倍率作为代表字段，记录每例迁移前后各来源的值。重开阅读器检查结果；本约定不要求已打开页面实时同步。

| 场景与准备 | 操作 | 预期 |
| --- | --- | --- |
| GM 有合法共享值，本站统一/独立旧值冲突 | 依次从 EH/EX/NH 打开 | 合法共享值均保留 |
| GM 为空，本站统一与独立旧值均合法但冲突 | 首次打开，再从有不同旧值的站点打开 | 首站统一旧值先迁入；后续站点不覆盖合法共享值 |
| GM 部分缺失/无效，本站统一仅部分合法、独立设置补有其他项 | 初始化并重复打开 | 各项依次取共享、统一旧值、独立旧值、默认值；已合法项不被整体覆盖 |
| 所有来源都没有某项合法值 | 初始化 | 仅该项采用默认值；翻页动效按第 4 节矩阵 |
| 迁移已执行，保留旧副本 | 再次执行迁移 | 结果相同，旧副本仍可用于降级 |
| GM 不可用，多个 origin 有不同本地偏好 | 各站修改并重开 | 仅各自 origin 生效，无跨站共享假象 |
| 降级期间本站修改，随后恢复带有合法共享值的 GM | 再次初始化 | 合法共享值优先；仅缺失/无效项从本站补缺 |
| GM 可用，旧副本含非默认值 | 通过 UI 确认重置，再重开各站 | 已重置偏好不被旧副本重新导入，默认值按当前规则生成 |
| GM 不可用，本站存在旧副本 | 确认重置并在本站重开 | 本站重置生效且不复活；其他 origin 保持隔离 |

同时核实实际生产脚本的 GM 读写/重置能力与权限声明。确认对单个坏值的修复不会改变其余合法值。

## 4. 相关设置专项

- 翻页：执行 [翻页 quickstart](../001-add-pageflip-toggle/quickstart.md) 的首次初始化矩阵。无合法迁移值时，系统减少动态效果优先设无动效，否则桌面拟真、移动平移；三种已有合法值均保留。初始化后切换系统偏好、保存语言等其他设置、刷新和重开画集，动效不能意外变化。
- 放大镜：执行 [放大镜 quickstart](../001-add-pageview-magnifier/quickstart.md)。桌面设置与快捷菜单范围一致，任意整数 20–300、快捷 ±10 并钳制边界；尺寸和倍率长期保存、开关仅当前页面会话继承。视口受限时的临时尺寸不写回偏好；移动端保留桌面限制。
