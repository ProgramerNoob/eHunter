## 1. 下载格式

每个 ZIP 分包包含一个 UTF-8 `metadata.json`，保留七个字段：`introUrl`、`galleryTitle`、`totalPages`、`downloadTime`、`eHunterVersion`、`totalChunks`、`chunkIndex`。单包和多包都独立携带元数据。

沿用现有 `fflate` 生成标准 ZIP；元数据采用 JSON 单格式。此前的 YAML 与 `jszip`/`yaml` 计划已被此决策取代。

依据：原始需求明确写过 YAML；历史提交 `08b76ee` 已包含改用 JSON 的变更，本轮用户确认保留。当前生产者见 [GalleryDownloadService.ts](../../core/service/GalleryDownloadService.ts)。静态检索未发现仓库内读取该元数据的消费者，也未提出需要双格式的外部消费者。

**完成标准**：下载规格及验收统一检查 `metadata.json`，每包七个字段完整且分片信息正确。历史 YAML 方案标明已被替代，不把旧任务勾选视为新验收结果。

## 2. 翻页默认值

保留拟真、平移、无动效三个选项。只有在迁移后仍无合法偏好时，才按下表初始化，并记住计算出的实际动效：

| 条件 | 初始化结果 |
| --- | --- |
| 已有合法偏好，包括旧记录中恰好等于旧默认值的偏好 | 保留该值 |
| 无合法偏好，系统启用“减少动态效果” | 无动效 |
| 无合法偏好，系统未启用“减少动态效果”，桌面端 | 拟真 |
| 无合法偏好，系统未启用“减少动态效果”，移动端 | 平移 |

用户后来选择的动效覆盖已存值。初始化后，系统偏好变化不会重新决定动效；后续会话继续使用已存值。无效/缺失值先按下一节尝试补齐，再应用上表。清除该项偏好后，下次初始化重新计算。

本轮明确选择保留三项，因此不增加“自动”选项，也不增加运行时跟随系统变化的行为。旧记录没有可靠的显式选择标记，迁移时将合法值视为需要保留的偏好。

**完成标准**：覆盖桌面/移动 × 系统减少动态效果开/关的首次初始化，以及已有偏好、缺失/损坏值、重开阅读器和手动切换场景；保存其他设置不能改变已确定的动效。卷轴模式行为保持原有约定。

## 3. 设置共享与迁移

同一浏览器、同一油猴脚本安装下，EH、EX、NH 通过 GM 存储共享阅读偏好。GM 不可用时，降级为当前站点的 `localStorage`；该降级按 origin 隔离。此约定不包含跨设备同步。

迁移按以下顺序处理每个配置项：

1. 已有合法共享值优先保留。
2. 共享中缺失或无效的项，从当前站点旧偏好补齐；同站以合法统一设置优先，旧独立设置补缺。
3. 共享为空时，首次打开的站点先迁入其合法旧值；后续站点只补仍缺失或无效的项，不覆盖合法共享值。
4. 所有可用来源均无合法值时，才采用该项默认值；翻页动效遵循上一节。

保留本地旧数据用于回退。GM 恢复可用后仍按上述优先级处理：共享中已有的合法值优先于降级期间形成的本站值。迁移重复执行应得到一致结果。

这是一套自动迁移规则，不新增冲突选择界面。现有“清空缓存并重置全部设置”的确认与重置契约继续有效；实现迁移时须保证已被明确重置的偏好不会被保留的旧副本再次导入。

**完成标准**：补齐生产脚本所需的 GM 存储权限并核对实际可用性；验证 EH/EX/NH 共用偏好、GM 不可用时的本站降级、空共享存储迁入、多来源冲突、坏值补齐、重复迁移及重置后的结果。

## 4. 放大镜尺寸、记忆与可视边界

沿用仅桌面端可用的范围，默认取样区为 **80×80 CSS px**，默认倍率为 **3 倍**，倍率选项仍为 **2、3、4、5 倍**。

### 尺寸与入口

- 取样区边长允许 **20–300px 的整数**。
- 设置和快捷菜单覆盖同一范围；快捷加减每次 **10px**，跨越边界时停在 20 或 300，到达边界后对应按钮不可继续操作。
- 80px 表示默认取样边长，替代旧规格的固定 80×80 约定。

### 记忆范围

尺寸和倍率长期保存，使用上一节的共享与降级规则。开启状态仅在当前页面阅读会话中继承：翻页、书页/卷轴切换时保留；刷新或打开新页面默认关闭。

这替代旧规格中“所有放大镜状态仅会话有效”的约定。首次使用、无合法已存值时仍为 80px、3 倍、关闭。

### 放不下时的显示规则

可用空间是当前 PageView 与浏览器视口相交的可视区域。优先将正方形放大窗口放在焦点旁的可用位置；若按设定尺寸生成的窗口无法完整放下，采用 **倍率不变、临时缩小取样范围** 的方案。

- 实际取样参考框与放大窗口同步缩小，二者始终满足“放大窗口边长＝实际取样边长×所选倍率”。
- 保存的尺寸与倍率不变，空间恢复后恢复到设定的取样范围。20–300px 是用户设置范围；受可视空间限制的临时取样边长可以小于该范围下限。
- 优先避开焦点；空间不足时允许覆盖部分焦点，以保证放大窗口完整处于可视区域内。

例如：设定取样 200px、5 倍，本应生成 1000px 的放大窗口；若最多只能容纳 600px 的正方形，则临时取样 120px，仍显示为 5 倍的 600px 窗口。界面参考框同时变为 120px，已存设置仍是 200px、5 倍。

**完成标准**：验证自由整数值、20/300 边界、快捷加减与设置一致性、尺寸/倍率跨会话保存、开关会话继承，以及窗口缩小时保持倍率和完整可见、窗口恢复时还原范围。桌面端验证两个阅读模式；移动端验证原有阅读和菜单行为、放大镜桌面端限制。
